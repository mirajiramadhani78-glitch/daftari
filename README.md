# Mchina Agrovet: Daftari la biashara

App ya simu ya kurekodi mauzo, stoo, madeni, matumizi na ripoti za MCHINA AGROVET.
Inafanya kazi bila mtandao na inatuma data kwenye Firebase mtandao ukirudi.

- Mipangilio ya Firebase na barua pepe ya mmiliki: `config.js`
- Usibadilishe faili nyingine kwa mkono; matoleo mapya yanapakiwa kama yalivyo.
